# License guidance (org-wide note, not a license)

This file is guidance only. **It does not license anything.** There is no
org-wide LICENSE file in this repo on purpose: VisionVend repos are
currently all private, and their licensing postures differ (for example,
`visionvend-cam` is GPLv3 as a fork of MiBee Cam, while other repos carry
MIT, proprietary, or no license at all). A single blanket license pasted
here would misdescribe most of the org.

Rules:

1. **A repo's own LICENSE file governs that repo.** If a repo has no
   LICENSE file, its code is not open-source by default — do not treat it
   as licensed, and do not copy it elsewhere without 's approval.
2. **Do not add a LICENSE file to this `.github` repo** expecting it to
   apply org-wide. GitHub does not inherit a LICENSE from the `.github`
   repo the way it inherits CONTRIBUTING, CODE_OF_CONDUCT, SECURITY, and
   issue/PR templates.
3. **Before any repo goes public**, its LICENSE must be reviewed and set
   explicitly in that repo, and any license contradiction (badge vs.
   LICENSE file vs. package metadata) must be resolved first. Several
   org repos currently carry such contradictions.
4. **Third-party models and data have their own terms.** Sketchfab catalog
   entries, datasets, and model weights are governed by their upstream
   licenses (including NonCommercial / NoDerivs / ShareAlike / NoAI
   flags where present), not by any repo LICENSE.
5. **Free-models-only rule:** any 3D model collected for VisionVend must
   be free — no paid or store models, even for an exact product match.
