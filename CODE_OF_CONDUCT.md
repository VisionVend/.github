# Code of Conduct

This file lives in the VisionVend `.github` repo, so it is the default code
of conduct for every VisionVend org repo that does not define its own. A
repo's own `CODE_OF_CONDUCT.md` always takes precedence over this one.

## Our standards

VisionVend is a small, private org. Contributors are expected to be direct
and honest, to disagree openly when a technical call is wrong, and to keep
disagreement about the work — never personal.

Examples of unacceptable behavior include harassment, intimidation,
publishing another person's private information, and disruptive conduct in
shared channels.

## Enforcement

Instances of unacceptable behavior may be reported to the org owner
(, via the business contact in `profile/README.md`).
The owner will review and respond, and may remove, edit, or reject
contributions that do not align with this code, or remove a contributor
from org repos. All reports are kept confidential.
